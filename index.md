# Organization knowledge base

Agents start here, read the layer they need, and follow links down. Higher layers are shorter and more stable; lower layers are concrete and change more often. Each layer cites the one above it. Projects inherit this KB and add only what is specific to them ([constitution](/constitution.md), "What each project provides").

| Layer | What it holds | Location | Status |
| --- | --- | --- | --- |
| 1. Constitution | 8 non-negotiable articles, loaded into every agent's context | [constitution.md](/constitution.md) | draft |
| 2. Principles | 50 principles with stable IDs (SWEBOK v4.0 + AI-native) | [principles/](/principles/index.md) | draft |
| 3. Guidelines | Concrete rules per area, each refining principle IDs | [guidelines/](/guidelines/index.md) | 1 of 5 drafted |
| 4. Standards and templates | Artifact templates; coding standards and checklists to come | [standards/templates/](/standards/templates/index.md) | 3 templates drafted |
| 5. Org context | Glossary, security and regulatory policy, branding, SOPs, tech stack, ADR log | context/ | not yet written |
| 6. Exemplars | Good and bad examples of each artifact type | exemplars/ | not yet written |

Reference implementation of a project on this KB: [ieo](https://github.com/balaji-balu/ieo). Changes are recorded in [log.md](/log.md).
